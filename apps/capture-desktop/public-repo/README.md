# Miraiclip Recorder

Record your whole screen on macOS or Windows with your camera and voice. Miraiclip Recorder also logs clicks, shortcuts and scrolls in every app, so the Miraiclip editor can add zooms, a cursor highlight and steps automatically.

This repository only hosts the installers. The source is part of the Miraiclip SDK.

## Getting started

See the [desktop recorder guide](https://docs.miraiclip.com/screen-recordings/desktop-recorder) for permissions, recording and opening a recording in the editor.

Builds aren't signed yet, so the first launch shows a warning. On macOS, right-click the app and choose **Open**. On Windows, click **More info → Run anyway**.
