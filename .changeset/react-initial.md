First release: React bindings. `ProjectProvider` / `ProjectSessionProvider`, narrow state hooks (`useProjectState`, `useClips`, `useSelection`, `usePlayheadUs`, `usePlayheadRef`, `useUndoRedo`, …), `useCommands`, `PlaybackProvider` / `usePlayback` on the renderer's preview controller, and timeline behaviour hooks (`useCompositorPlayhead`, `useVisibleRange`, `usePlayheadFollow`, `useTimelineZoom`, `useEditorShortcuts`, `useGesture`). Requires @miraiclip/renderer 0.9.
